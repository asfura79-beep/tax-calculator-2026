# Налоговый калькулятор 2026

Статический веб-калькулятор для сравнения налоговых режимов ИП и ООО в модели 2026 года.
Приложение показывает доступные режимы, матрицу сравнения по НДС, график чистой прибыли и детализацию выбранного расчета.

Основной пользовательский интерфейс находится в `index.html` и работает без сборки. Для отображения страницы используются CDN-версии React, Tailwind CSS и Lucide Icons, поэтому при открытии файла нужен доступ к интернету.

## Расчетная модель

Расчетное ядро перенесено по Excel-модели `Калькулятор_налоговой_нагрузки_2026.xlsx`.
Сам исходный Excel-файл в проект не входит и исключен через `.gitignore`.

Карта зависимостей вычислений находится в `docs/calculation-dependency-map.md`.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
py -3 -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

## Проверка расчетов

```bash
npm test
```

Тесты проверяют расчетный модуль в `src/` как регрессионную опору для формул. Опубликованный калькулятор при этом запускается из `index.html`.

## Структура проекта

- `index.html` - основной статический калькулятор.
- `src/` - модульная версия расчетного кода, используемая текущими тестами.
- `tests/` - регрессионные тесты расчетов.
- `docs/` - документация по расчетной модели.
- `tools/` - служебные Python-скрипты для анализа исходной Excel-модели; для работы калькулятора, тестов и запуска страницы не требуются.
- `package.json` - npm-скрипт для запуска тестов.

## Публикация

Перед публикацией проверьте, что в репозиторий не добавлены исходные Excel-файлы, `.env`, ключи, токены, временные файлы и приватные выгрузки. Эти типы файлов исключены в `.gitignore`.

Кнопка настроек защищена паролем внутри статического HTML. Такой пароль подходит только как простое ограничение от случайного изменения настроек в браузере и не является полноценной серверной защитой.
